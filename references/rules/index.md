# Code Rules

代码生成与审查必须严格遵守以下规范。

## 规范文件

- [阿里巴巴 Java 开发规范](alibaba-java-coding-standards.md) — 基于《阿里巴巴 Java 开发手册（黄山版）》整理，涵盖编程规约、异常日志、单元测试、安全规约、MySQL 数据库、工程结构、设计规约七个维度
- [设计模式使用规范](design-pattern-guidelines.md) — 基于 GoF 23 种设计模式和 SOLID 原则，定义模式选用规则、适用/禁止场景和反模式清单
- [工作流约束规范](workflow-constraints.md) — 约束 Git 分支/提交、文件操作、数据库运维、执行计划、文档同步和生成文档忽略等行为边界，禁止直接在 master/main 分支修改被跟踪文件

## 约束力分级

| 级别 | 含义 |
|---|---|
| **【强制】** | 必须遵守，违反将导致代码质量问题或潜在缺陷 |
| **【推荐】** | 建议遵守，有助于提升代码质量 |
| **【参考】** | 提供背景理解，非必须遵守 |
